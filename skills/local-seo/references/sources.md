## Tool behaviour (sitetiller 0.1.0)
- `cli/lib/schema-lint.mjs` LocalBusiness rule: required `name`, `address`; recommended `telephone`, `openingHoursSpecification`, `geo`; subtypes mapped to LocalBusiness: Restaurant, Store, Dentist (other subtypes, such as DaySpa, are not mapped and get no checks). Source read 2026-11-12.
- `schema` returns `types` and `findings[]` only; it does not return the property values, so NAP comparison is read from the visible page.
